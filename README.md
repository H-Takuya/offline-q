# ルーンの草原

ブラウザで遊べる、ラグナロクオンライン風の斜め見下ろしアクションRPGです。
`index.html` をブラウザで開くだけで遊べます（インストール不要・1ファイル完結）。

## 遊び方

| 操作 | 内容 |
|---|---|
| 左クリック | 移動 / モンスターを攻撃 / NPCに話しかける / アイテムを拾う |
| 押しっぱなし | 歩き続ける |
| マウスホイール | 拡大・縮小 |
| `1`〜`9` | スキル・アイテム |
| `Q` / `W` / `R` | アコライト / ハンター / マジシャンに切り替え |
| `A` / `E` / `S` | ステータス / アイテム / スキル |
| `Z`（Insert） | 座る（回復2倍） |
| `Enter` | チャット（`/!` `/?` `/ho` `/lv` `/thx` でエモーション、`/sit` で座る） |

## 主な仕様

- 職業：アコライト（殴り型）、ハンター、マジシャン（詠唱魔法、DEXで詠唱短縮）。ステータス・スキル・武器は職業ごとに別、レベルとアイテムは共通
- 傭兵：町の「傭兵ギルド ガルド」で、アコライト・ハンター・マジシャンから1人を 5,000z / 10分 で雇える。回復・支援、弓、魔法でそれぞれ一緒に戦ってくれる。収集係「ハーヴェスト」（同額・同時に雇える）は落ちているアイテムとZenyを拾って届けてくれる
- 経験値1000倍、Base / Job Lv 999まで
- Job Lv 30ごとに全スキルの上限が+1
- ボス：最初は1体、1分ごとに1体ずつ増える（最大10体）。Base Lv100ごとに強いボスが解放され、弱いボスは少しずつ出なくなる
- アコライト耐性 / ハンター耐性のボスあり（耐性職のダメージは1/10）
- Base Lvが上がると町が発展する（花壇・街灯・旗・黄金の噴水・天使像・虹など）
- 攻略マップ「ピラミッド」：町の「待ち人 ネフェル」に話しかけると行ける。安全地帯は入口の光る9マスだけで、敵は多く、気づくとすぐ寄ってくる。敵の強さは自分のBase Lvに合わせて変わり、ボス「砂塵の王ファラオン」も出る。帰るときは「帰還の神官 アニ」に話しかける
- 最終ダンジョン「終焉の神殿」：Base Lv999で町の「時の番人 クロノ」から行ける。最奥の「終焉の王 アポカリオン」は赤い円の範囲攻撃を使う
- 転生：終焉の王を倒すと、Base / Job Lv を 1 に戻して再出発できる。ステータス・スキル・装備などはそのままで、強さは転生前のLv相当を引き継ぐ（何度でも可、転生するたびに神殿の敵が強くなる）
- オリジナルBGM「石畳の都のワルツ」「砂の迷宮」「終焉の鼓動」と効果音（Web Audioで生成）
- 進行状況はブラウザに自動保存

モンスター・アイテム・音楽はすべてオリジナルです。
