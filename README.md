# ルーンの草原

ブラウザで遊べる、ラグナロクオンライン風の斜め見下ろしアクションRPGです。
`index.html` をブラウザで開くだけで遊べます（インストール不要・1ファイル完結）。

## 遊び方

| 操作 | 内容 |
|---|---|
| 左クリック | 移動 / モンスターを攻撃 / NPCに話しかける / アイテムを拾う |
| 押しっぱなし | 歩き続ける |
| マウスホイール | 拡大・縮小 |
| `1`〜`9` | スキル・アイテム |
| `Q` / `W` / `R` | アコライト / ハンター / マジシャンに切り替え |
| `A` / `E` / `S` / `J` | ステータス / アイテム / スキル / 物語（これまでのあらすじ） |
| `Z`（Insert） | 座る（回復2倍） |
| `Enter` | チャット（`/!` `/?` `/ho` `/lv` `/thx` でエモーション、`/sit` で座る） |

## ストーリー

時を刻む石〈ルーン〉が砕け、魔物が何度でも甦るようになった世界。3つの「ルーンの欠片」を集め、時を喰らう「終焉の王」を倒す物語です。

話しかけるべきNPCの頭上には「!」マークが出て、ステータス窓に今の章と目標が表示されます。
会話は顔アイコンつきで1文字ずつ表示され、ときどき返事を選べます。町や港・雪の村の「依頼掲示板」ではサイドクエスト（青い「?」）を受けられます。

## 主な仕様

- 職業：ステータス・スキル・武器は職業ごとに別、レベルとアイテムは共通
- 転職：町の「転職官 ギルベルト」に話しかけると、Job Lv100で2次職、Job Lv200で3次職になれる。スキルは転職するごとに増える
  - アコライト → プリースト → ハイプリースト
  - アーチャー → ハンター → スナイパー
  - マジシャン → ウィザード → ハイウィザード
  - アコライト：回復・支援・物理殴り（ヒール、ブレッシング、速度増加、エンジェラス、マグニフィカート、グランドクロス）
  - ハンター：単体火力最強（ダブルストレイフィング、ブリッツビートは3×3を巻き込みダメージを分け合う、罠）
  - マジシャン：範囲火力最強（ファイアーボルト、ファイアーボール、サンダーストーム、ストームガスト（位置指定・ノックバック）、ファイアーウォール（ノックバック）、セーフティウォール。DEXで詠唱短縮）
- 傭兵：町の「傭兵ギルド ガルド」で、アコライト・ハンター・マジシャン・バードから2人まで雇える（1人目 5,000z、2人目 5,000,000z / 10分）。回復・支援、弓、魔法でそれぞれ一緒に戦ってくれる。バードは「ブラギの詩」を奏で、足元の9マス（3×3、地面が光る）の中にいる間は詠唱時間が50%・スキルのディレイ（スキルを使ったあとの待ち時間）が半分になる。効果中は足元に金色の輪と音符が出る。バードは冒険者のすぐそばについて歩く。収集係「ハーヴェスト」（同額・同時に雇える）は落ちているアイテムとZenyを拾って届けてくれる
- カード：ドロップすると虹色の光の柱と、カードの絵がくるっと回る「CARD!」の演出が出る
  - カードはアイテム窓の「カード帳」タブで、ふつうのアイテムとは別に管理。全カードに落とすモンスターの絵つき。集めた種類数が表示され、まだ手に入れていないカードは黒い影で見える。ボスのカードは金の枠
  - 特殊効果つきのボスカード：時喰らいの海竜カード（詠唱時間が半分）、氷牙の王カード（ASPD上限195に限界突破）、氷竜グレイシアカード（移動速度+30%）
- 爽快ボーナス：5秒以内に倒し続けるとコンボ。5体ごとに経験値+10%（5コンボで+10%、10コンボで+20%…）。最高コンボ数も記録
- 経験値300倍、Base / Job Lv 999まで。初回（転生前）の旅は Base Lv200 から経験値がさらに2倍
- Job Lv 30ごとに全スキルの上限が+1
- ボス：最初は1体、1分ごとに1体ずつ増える（最大10体）。Base Lv100ごとに強いボスが解放され、弱いボスは少しずつ出なくなる
- アコライト耐性 / ハンター耐性のボスあり（耐性職のダメージは1/10）
- Base Lvが上がると町が発展する（花壇・街灯・旗・黄金の噴水・天使像・虹など）
- 攻略マップ「ピラミッド」：町の「待ち人 ネフェル」に話しかけると行ける。安全地帯は入口の光る9マスだけで、敵は多く、気づくとすぐ寄ってくる。敵の強さは自分のBase Lvに合わせて変わり、ボス「砂塵の王ファラオン」も出る。帰るときは「帰還の神官 アニ」に話しかける
- 港町マリナと潮風の海岸（第2部）：転生後、町の「船乗り ガスパル」の船で行ける海辺の町とフィールド。ヤシの木・桟橋・灯台があり、ボス「海賊王 バルバロ」は大砲（オレンジの円）を撃ってくる
- 海底神殿（第2部）：港町の灯台守オルカから行けるダンジョン。泡が立ちのぼる青緑の神殿。中ボス「深海の番人 リヴァイア」（激流で凍結）とラスボス「時喰らいの海竜 タラッサ」（大渦）
- 中盤ダンジョン「凍てつく氷窟」：Base Lv300から、町の「氷窟の案内人 ユキ」に話しかけると行ける。ピラミッドより強く数も多い敵が出る。ボス「氷竜グレイシア」の冷気（青い円）を浴びると2秒間凍って動けなくなる
- 雪の村フロスト・白銀の雪原・氷晶の城（第3部）：オーロラと雪が舞う北の地。ボス「氷牙の王 グラキエス」と「氷晶の女王 セルシア」は冷気で凍らせてくる
- 封印のダンジョン（第1部）：「古代樹海」（Lv450〜・木の葉が舞う緑の迷宮）、「灼熱の火山洞」（Lv650〜・火の粉が立ちのぼる溶岩の洞窟）、「天空の時計塔」（Lv850〜・金色の光が漂う時計仕掛けの塔）。町のリーフ・ガンツ・ステラから行ける。敵は自分のLvに合わせて強くなり、ボスはそれぞれ毒の花粉（緑）・炎（オレンジ）・時止め（金色、凍結）の範囲攻撃を使う
- 最終ダンジョン「終焉の神殿」：Base Lv999で町の「時の番人 クロノ」から行ける。最奥の「終焉の王 アポカリオン」は赤い円の範囲攻撃を使う
- やりこみ（ルーンの草原・港町マリナ・雪の村フロストにいる「夢幻の門番 ノクス」から。どちらも安全地帯なし、ミニマップの「町へ戻る」でいつでも帰れる）
  - ボスの闘技場（転生4回目から）：小さな円形の闘技場に、カードを持つボスだけが常に5体。倒すと5秒後に別のボスが現れる。カードのドロップ率は通常の約2倍
  - ナイトメア（転生後）：倒すたびに深度+1、敵のLvが3ずつ・HPと攻撃力が1%ずつ上がり続けるエンドレス。深度は保存され、町に戻っても次は続きから。50体ごとにカードを持つ「悪夢の化身」が現れる
- 転生：終焉の王を倒すと、Base / Job Lv を 1 に戻して再出発できる。ステータス・スキル・装備などはそのままで、強さは転生前のLv相当を引き継ぐ（何度でも可、転生するたびに神殿の敵が強くなる）
- オリジナルBGM「石畳の都のワルツ」「潮風の港」「砂の迷宮」「凍てつく氷窟」「終焉の鼓動」「海底神殿」「雪の村」「氷晶の城」「古代樹海」「灼熱の火山洞」「天空の時計塔」と効果音（すべてWeb Audioでその場で合成）。ホールの残響、ステレオ定位、ストリングス・金管・ハープ・ベル（FM合成）・合唱・ティンパニなどの音色を、マップごとに編成を変えて鳴らす。2周目は楽器が増える
- 進行状況はブラウザに自動保存

モンスター・アイテム・音楽はすべてオリジナルです。
